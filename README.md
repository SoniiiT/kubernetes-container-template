# kubernetes-container-template

## Einführung

Diese Repository enthält vorkonfigurierte Container-Templates für Kubernetes. Kubernetes (oft als K8s abgekürzt) ist ein Open-Source-System zur Automatisierung der Bereitstellung, Skalierung und Verwaltung von containerisierten Anwendungen. Es ermöglicht die Orchestrierung von Containern über mehrere Hosts hinweg und bietet Funktionen wie:

- Automatische Skalierung
- Lastverteilung
- Selbstheilung
- Service Discovery
- Konfigurationsmanagement

## Container Templates

Die in dieser Repository enthaltenen Templates bieten vorkonfigurierte Lösungen für verschiedene Anwendungsfälle. Jedes Template ist mit den notwendigen Konfigurationen, Ressourcenlimits und Best Practices für die Produktion ausgestattet.
